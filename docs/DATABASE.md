# Модели данных

Сервер использует **две отдельные базы данных** на одном MongoDB-сервере.

## users_db — Пользователи

**Модель:** `src/models/user.js`

| Поле | Тип | Обязательно | По умолчанию | Описание |
|------|-----|------------|-------------|---------|
| `name` | String | Да | — | Имя пользователя |
| `email` | String | Да | — | Уникальный email |
| `password` | String | Да | — | Хеш пароля (bcrypt, 12 раундов) |
| `currentReiting` | Number | Нет | `800` | Текущий рейтинг |
| `token` | String | Нет | `""` | JWT-токен сессии |

## game_db — Игровые сессии

**Модель:** `src/models/game.js`

| Поле | Тип | Обязательно | По умолчанию | Описание |
|------|-----|------------|-------------|---------|
| `statusGame` | String | Нет | `"open"` | `"open"` — поиск оппонента, `"close"` — игра идёт |
| `position` | Array | Нет | начальная позиция | Текущая позиция на доске (FEN-подобный формат) |
| `typeGame` | String | Нет | `"standart"` | Тип игры |
| `timeControl` | Number | Нет | `180` | Контроль времени (секунды) |
| `timePluse` | Number | Нет | `2` | Добавление времени за ход (секунды) |
| `nameWite` | String | Да | — | Имя белых |
| `reitingWite` | Number | Да | — | Рейтинг белых |
| `nameBlack` | String | Да | — | Имя чёрных |
| `reitingBlack` | Number | Да | — | Рейтинг чёрных |
| `ownerWite` | ObjectId | Нет | — | Ссылка на пользователя (белые) |
| `ownerBlack` | ObjectId | Нет | — | Ссылка на пользователя (чёрные) |
| `result` | String | Нет | `"pending"` | `"pending"`, `"1-0"`, `"0-1"`, `"0.5-0.5"` |

## Схема поиска оппонента

При создании новой игры сервер ищет открытую сессию (`statusGame: "open"`) с совпадающими параметрами (`typeGame`, `timeControl`, `timePluse`). Если находится — игра начинается, иначе создаётся новая сессия в режиме поиска.
